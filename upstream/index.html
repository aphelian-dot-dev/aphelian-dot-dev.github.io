    Cookie details + how to inspect

    aphelian_score_history contains URL-encoded JSON: version plus each run's score, win/loss, best chain, rite seconds, and completion time. No name or unique identifier is stored. It is host-only, uses Path=/ and SameSite=Strict, and adds Secure on HTTPS. Its one-year Max-Age renews after each saved rite; because renewal applies to the whole cookie, older entries may remain longer than one year while you continue saving. It cannot be HttpOnly because this page must read it to draw the archive.

    Because it is a cookie, your browser includes it in requests to this site. Aphelian is a static game and contains no code that sends or uses it for anything beyond this on-page archive.

    Archive changes use Web Locks so tabs cannot overwrite one another. If Web Locks are unavailable, the archive stays off. A malformed or unsupported-version same-name cookie is marked incompatible; it does not grant consent and will not be overwritten. Use Remove incompatible cookie when offered, or follow the manual steps below.
